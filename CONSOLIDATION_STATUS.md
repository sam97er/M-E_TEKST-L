# ME Tekstil AI — Consolidation Workspace

This package is a consolidation workspace based on all six supplied reference projects.

## Important status
- `android-app/` starts from the feature-rich Android reference.
- `reference-sources/` contains copies of all six projects for controlled comparison.
- `brand-assets/` contains the supplied M&E Tekstil brand images.
- This is not represented as a fully verified production release until Android dependency
  resolution, Gradle build, unit tests, lint, and device testing complete in a real Android
  build environment.

## Product decisions
- App name: ME Tekstil AI
- API keys: entered from the app Settings screen and stored securely; never commit secrets.
- Brand: gold/black logo for app identity and white/black logo for welcome/about surfaces.
- No section is permanently frozen; all modules remain changeable unless explicitly finalized later.
